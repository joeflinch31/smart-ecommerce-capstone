## 🚀 How to Run Locally

1. Install [XAMPP](https://www.apachefriends.org/)
2. Start Apache and MySQL
3. Clone or copy to `C:\xampp\htdocs\`
4. Import `week5db.sql` into phpMyAdmin
5. Open `http://localhost/week5/index.php`
